# Catálogo Multiespectral AOI — 3.5.4

Atualizada a simbologia NDVI para uma escala contínua de vermelho a verde escuro, passando por laranja, amarelo e verde claro. Os valores altos aparecem em verde escuro, com escala fixa de −1 a +1. Mesma paleta na prévia, importação manual e por comandos. Cálculo, resolução, valores e NoData preservados. Mantidas as melhorias de interface da versão instalada 3.5.3.

Para instalar: Complementos → Gerenciar e Instalar Complementos → Instalar a partir de ZIP. Selecione Catalogo_Multiespectral_AOI_v3.5.4_QGIS.zip.

Para o catálogo oficial: envie esse mesmo ZIP instalável. O arquivo Fontes.zip é para desenvolvimento.

Camadas já salvas não mudam automaticamente: reimporte o NDVI no plugin para aplicar a nova paleta. A escala de cores não classifica automaticamente usos do solo.
